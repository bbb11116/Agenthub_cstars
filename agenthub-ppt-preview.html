AgentHub 解决什么问题？

把本地代码目录变成 AI 协作空间，让多个 Agent 围绕同一个 Workspace 分工、执行、审查和沉淀上下文。

本地 Workspace

绑定真实项目目录，文件、Git、上下文都围绕项目展开。

主 Agent 调度

Orchestrator 理解任务、拆解步骤，并选择合适的子 Agent。

多 Agent 协作

子 Agent 可绑定不同技能与 Runtime，承担专业任务。

用户可控落盘

代码修改先生成 DiffProposal，确认后才真正写入文件。

Value

为什么 AgentHub 有价值？

AgentHub 不是普通聊天工具，而是面向真实项目工作的本地多 Agent 工作台。它把上下文、调度、执行、审查和产物管理放在同一个应用里，降低多 Agent 协作的使用成本。

让 AI 协作进入项目上下文，而不是停留在孤立对话里。

适合场景
  • 代码项目辅助开发
  • 多角色任务拆解
  • 文档、网页、PPT 等产物生成
  • 本地 CLI Agent 统一管理
  • 需要审查和可控落盘的 AI 工作流
